# Оффлайн-читалка FB2 (на основе читалки fantasy-worlds.org)

Статическое PWA: **полка + читалка FB2**, которое работает целиком на вашем
устройстве и не зависит от сайта. Раньше книги на fantasy-worlds.org
рендерились сервером в HTML; здесь серверную часть заменил локальный
конвертер `fb2.js`, который превращает обычный `.fb2`-файл в ту же разметку,
что ждёт движок чтения (`reader.js` практически не изменён).

## Возможности

- **Импорт FB2** — кнопка «Добавить FB2» или просто перетащить файлы в окно.
  Поддерживаются UTF-8 и Windows-1251 (кодировка определяется по прологу XML).
- **Библиотека** — все книги хранятся в IndexedDB браузера: карточки,
  обложка, аннотация, серии, прогресс чтения.
- **Читалка** — как на сайте: 4 темы (светлая/сепия/серая/тёмная), 4 шрифта,
  прокрутка/главы/страницы, колонки, размер шрифта, переносы, полужирная
  типографика, сноски, сохранение позиции.
- **Оффлайн** — Service Worker кэширует оболочку; книги лежат в IndexedDB
  и доступны без сети после первого онлайн-открытия приложения.
- **Бэкап** — у каждой книги меню «Скачать FB2», возвращающее исходный файл.

## Как развернуть

Куда угодно, откуда отдаются статические файлы по HTTPS (обязательно для
Service Worker). Например — GitHub Pages:

```bash
# создайте репозиторий и залейте содержимое этой папки
git init
git add .
git commit -m "offline fb2 reader"
git branch -M main
git remote add origin https://github.com/<you>/<repo>.git
git push -u origin main
```

Дальше в настройках репозитория: **Settings → Pages → Deploy from a branch →
main / (root)**. Сайт откроется по адресу `https://<you>.github.io/<repo>/`.

> Если репозиторий называется `<you>.github.io`, приложение будет в корне
> домена. Service Worker строит все пути относительно текущего адреса,
> поэтому под-пути (страницы проектов) тоже работают.

### Быстрая локальная проверка

```bash
python3 -m http.server 8000
# откройте http://localhost:8000
```

`file://` не подходит: IndexedDB и Service Worker в этом режиме ограничены.

## Установка как приложение

На телефоне/компьютере: откройте сайт → «Добавить на главный экран»
(«Установить приложение»). Работает как обычное приложение, в том числе
полностью оффлайн.

## Структура

| Файл | Назначение |
| --- | --- |
| `index.html`, `shelf.js` | Полка: импорт, поиск, список, удаление, бэкап |
| `read.html`, `reader.js`, `reader.css` | Читалка (reader.js почти без изменений с сайта) |
| `fb2.js` | Конвертер FB2 → разметка читалки (вместо сервера) |
| `book-db.js` | IndexedDB: карточки книг, контент, прогресс |
| `sw.js`, `manifest.json`, `offline.html` | Оффлайн-обвязка (PWA) |
| `favicon.svg` | Иконка |
| `_src/` | Оригиналы, скачанные с сайта (для справки), в работу не входят |

> Шрифты подключены с Google Fonts как необязательное украшение: без сети
> читалка использует системные (`serif`/`sans-serif`/`monospace`), текст
> остаётся читаемым. Всё остальное кэширует Service Worker.

## Как это работает

Движок чтения (из `_src/reader.js`) ожидает в `#book-meta` JSON метаданных
и готовую разметку в `#book-content`. Сервер сайта генерировал их заранее.
В оффлайн-версии при импорте `fb2.js` делает то же самое прямо в браузере:

- `section#sN`, заголовки `<h2>…</h2>`, абзацы `p1..pN` (сквозная нумерация);
- `toc`, `section_ids`, `section_ranges`, `paragraph_count` для пагинации;
- сноски `a.note__ref[data-note-id]` + модалка;
- картинки `<binary>` → data-URL, обложка → на полку;
- позиция чтения сохраняется как номер абзаца.

`reader.js` отличается от оригинала только подгрузкой книги из IndexedDB
(функция `loadLocalBook`), прямым `src` для картинок и отсутствием
серверного блока прогресса/SW-сообщений.

## Лицензия/замечание

Код читалки взят с reader.fantasy-worlds.org и адаптирован для локального
использования. Импортируйте по-настоящему свободные книги и те, что уже
легально есть у вас на устройстве.
